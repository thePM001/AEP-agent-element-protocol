# Lattice Memory (AEP 2.9)

Lattice Memory stores forensic attractors and health telemetry and it never admits, because looking similar to a past allow is not allow and Base Node is the only live evaluator. Attractors do not skip the compiled pulse or collect-all walls. Writing walls use CORRECTWRITING_EN and writing:* ids.

## Backends

sqlite is the durable default so the Base Node sqlite file holds vector rows plus metadata, the in-memory backend is a process-local fast path for similarity search.

## What Memory does not do

Memory does not Admit, does not Apply and does not rewrite agent permission. A nearby past allow is evidence for a later reader and is not membership proof for this capsule.
