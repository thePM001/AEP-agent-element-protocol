# Minimal wrap (AEP 2.8.6)

This wrap imports public kernel names from Base Node. Base Node is the only live evaluator and the wrap is not a second evaluator. An empty agent permission list refuses. Compiled pulse is PULSE_MS 1000. Writing walls use CORRECTWRITING_EN and writing:* ids.

From the repo root, cargo run against examples/minimal-wrap/Cargo.toml prints allow true.

UCB is not used here, enqueue is not Admit and TypeScript processEvent is not product Admit.
