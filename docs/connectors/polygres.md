# Polygres connector (AEP 2.8.5)

Polygres is an optional Lattice Memory backend documented here as backend notes only and it is not a default compose service, so do not add Polygres to the public compose file. Writing walls use CORRECTWRITING_EN and writing:* ids.

Lattice Memory never admits and looking similar to a past allow is not allow, so a Polygres graph, vector, text or hybrid hit is not Admit and Base Node stays the only live evaluator. The builder still presents a manifest and a sealed capsule. Base Node still freezes the clock at seal, waits the compiled 1000 ms pulse, runs every written wall together, records the ledger and applies only after Admit.

Use sqlite as the default durable store and attach Polygres only when an operator wants an optional retrieval backend beside that store. See docs/LATTICE-MEMORY.md.
