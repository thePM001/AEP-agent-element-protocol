# Admit writing walls

This folder belongs to component 04 (Admit Gate) and the README of the whole component is `AEP-Components/admit/README.md`.

The crate compiles the writing rules of the policy file `AEP-Policy-System/reference/writing.gap` into walls and folds them into the same collect-all pass as every other wall.

| Path | Role |
|------|------|
| `crate/` | The Rust crate `aep-admit-writing-walls` |

Run its tests from the repository root with `cargo test -p aep-admit-writing-walls`.
