# One live evaluation

This folder belongs to component 01 (AEP Base Node) and the README of the whole component is `AEP-Base-Node/README.md`.

The crate makes sure one Admit function judges an opened capsule. It compiles the product wall crates onto the live entry and its source check fails when a second evaluation path appears beside the envelope Admit.

| Path | Role |
|------|------|
| `crate/` | The Rust crate `aep-one-live-evaluation` |

Run its tests from the repository root with `cargo test -p aep-one-live-evaluation`.
