# AEP Proxy

MCP and shell proxy servers under lattice governance.

- **Component ID:** `proxy`
- **Path:** `proxy/`
- **Manifest:** `AEP-Base-Node/registry/components/proxy.json`

Re-exported by `typescript-sdk/` for programmatic access. Runtime code lives in `lib/`.

MCP backend transport forwards policy-allowed tool calls over stdio JSON-RPC and SSE HTTP with mcp-session-id.
